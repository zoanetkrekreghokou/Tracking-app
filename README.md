# Tracking app

Tracker des images et objets. Compile en APK Android avec Kivy + OpenCV.

## Fichiers
- `main.py` : code du tracker + capture d’écran Android
- `requirements.txt` : dépendances Python
- `buildozer.spec` : config de compilation Android
